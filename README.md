# Student-Financial-Agent-Lab
基于多 Agent 协同架构的大宗商品及基金量化分析实验室

## 1. 项目背景
作为一名在校学生，我发现个人投资者在处理复杂金融数据（如非农数据 NFP）时常受情绪干扰。本项目旨在构建一个基于 AI Agent 的决策辅助系统。

## 2. 技术逻辑
本项目采用长链推理（CoT）架构：
* **数据感知层**: 监控实时行情。
* **逻辑推理层**: 模拟“数据 -> 政策 -> 价格”的因果推演。
* **风险控制层**: 结合学生身份的预算限制进行模拟风控。

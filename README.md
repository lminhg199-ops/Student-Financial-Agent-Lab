# Student-Financial-Agent-Lab (SFAL)
基于多 Agent 协同架构的大宗商品交易决策辅助系统

## 项目简介
本项目是一个面向个人投资者的 AI 决策辅助框架，旨在解决学生群体在面对宏观经济波动（如非农 NFP、美联储议息）时，信息处理滞后及情绪化决策的问题。本项目由学生独立开发，核心在于利用长链推理（CoT）提升金融建议的可解释性。

## 核心架构
本项目采用多 Agent 协作流：
1. **Sensory Agent**: 实时监控行情与新闻情绪。
2. **Reasoning Agent**: 负责逻辑推演（例如：NFP数据 -> 利率预期变动 -> 资产价格重塑）。
3. **Review Agent**: 引入博弈机制，对决策进行压力测试。
